使用示例

同一端口两种协议均可连接
# HTTP 代理（curl） curl -x http://127.0.0.1:1080 https://example.com # SOCKS5 代理（curl） curl -x socks5://127.0.0.1:1080 https://example.com # 浏览器 / 系统代理 协议: HTTP 或 SOCKS5 地址: 127.0.0.1 端口: 1080
